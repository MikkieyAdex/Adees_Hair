Adees Hair — Front-End E-Commerce Template
Welcome to the Adees Hair front-end project! This project is a feature-rich, responsive e-commerce homepage tailored for a hair extension and beauty brand. Built as a practice project and portfolio piece , it mimics modern online store designs using modern web standard technologies.

🌟 Key Features

Responsive Layout: Powered by Bootstrap 5.3's grid system, making the layout look great on desktop, tablet, and mobile screens.
Custom Brand Styling: A distinct white and purple color theme.
Built-in Dark Mode: Dynamic light/dark mode toggling using Bootstrap 5.3’s data-bs-theme attribute.
Hover-Activated Dropdowns: Navigation menu dropdowns open on hover for desktop users while remaining touch-friendly on mobile devices.
Custom Logo Integration.
Hero Image Carousel & Announcement Slider: Rotating announcement bar and smooth-fading hero banner for store promotions.
Interactive Product Gallery: Dynamic product main-image switching upon clicking thumbnail options.
Category Grid with Hover Effects: Animated zoom transformations on category highlights (Wigs, HD Lace, Raw Bundles).
Social & Trust Sections: Includes brand trust banners, an Instagram feed grid, customer reviews, and a blog/press preview section.

🛠️ Built With

HTML5 
CSS3 (Custom hover dynamics and transition effects) 
JavaScript (ES6) (Image switcher dynamic functions & dark mode toggling) 
Bootstrap 5.3 (UI Framework, Grid system, dynamic theme engine)
